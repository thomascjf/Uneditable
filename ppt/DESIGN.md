# 指纹上链 · 路演 2 页设计约定

## 全局视觉约定（全篇不换）

- 场景：通用（技术路演 / 黑客松投屏），风格取向「科技未来」但底色按 brief 锁定。
- 画布：1280×720（16:9）；padding 上下左右各 60px；内容区 1160×600（y 60–660）。
- 底色 bg：`#070a0f`（近黑）。
- 文字：一级 `#FFFFFF`、二级 `#B6C0CC`、辅助 `#7E8A99`；全页文字色 ≤ 4 种。
- 强调色 accent：`#A78BFA`（亮紫）—— 全篇只用于 P2「BlitzBoard 合约」节点内 `0x0100 P256 预编译 · 合约内验签` 这一处标注，唯一高亮。P1 不使用强调色。
- 中性描边/箭头：`#2E3742`（节点边框）、`#4A5563`（箭头）。
- 字体：思源黑体（回退 Microsoft YaHei / sans-serif）；中文优先，标题 Bold，正文 Regular。
- 字号阶梯：钩子 54px（全篇最大）/ 大标题 46px / 副标题 22px / 底部信息 16px / 节点标题 18px / 节点内标注 14px。
- 视觉母题：深色满底 + 1px 中性细描边；无阴影、无渐变、无配图、无 emoji。
- 版式节奏：P1 大字报式（左对齐、大留白）；P2 流程链（横向五节点 + 箭头），两页构图轴与密度明显不同。

## 逐页字段

### P1
- title：指纹上链
- type：cover / role：hero / rhythm：peak
- layout：大字报式（左对齐 + 大面积留白）
- visual：纯文字，无图；钩子为视觉锚点
- density：字数约 60 / 图片 0 张 / 留白约 55%
- anti_pattern：禁止加页、禁止团队介绍/功能清单、禁止花哨配图、禁止任何强调色
- description：大标题「指纹上链」；最大字号钩子「没碰过钱包的人，10 秒投一票；这一票，谁都改不掉。」；副标题「按一下指纹，10 秒上链；换一份名单，下一场活动就能复用」；底部「Monad Testnet · 合约 0x92d7bd2f…4e24f1f09」。

### P2
- title：（无标题，纯架构图）
- type：content / role：supporting / rhythm：valley
- layout：流程链 g（横向五节点 + 箭头）
- visual：L1 五节点横向架构图（Box+Text 节点 + SVG 箭头），占中部，上下大留白
- density：字数约 70 / 图片 0 张 / 留白约 60%
- anti_pattern：禁止等宽卡片当并列要点堆砌、禁止给非 BlitzBoard 节点标注任何 Monad 特性、禁止出现 600ms/低手续费/TPS/流式执行/索引器
- description：手机扫码 → passkey 指纹签名 → 转发器代付 gas → BlitzBoard 合约（唯一高亮 `0x0100 P256 预编译 · 合约内验签`）→ 双栏大屏（左：中心化数据库·可改 / 右：Monad 链上·改不了）。
